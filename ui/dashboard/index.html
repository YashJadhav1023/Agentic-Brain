How a task flows

Every task passes through these eight stages, from your request to a reviewed, merged change.

  1. 1You ask

    You dispatch a task, or an agent picks up from the last handoff.

  2. 2Shared brain

    Recalls the session, the previous handoff and relevant memories.

  3. 3Smart router

    Scores every available agent on eight factors and picks the best one, with a failover order.

  4. 4Context optimizer

    Trims and de-duplicates context so it fits the model's token budget.

  5. 5Agent does the work

    Antigravity, Kiro or Cline runs the task in an isolated sandbox.

  6. 6Failover guard

    On a rate limit or quota error the task moves to the next agent automatically.

  7. 7Verification

    One bounded, non-recursive check confirms the result.

  8. 8Review & merge

    You approve the change in Worktrees, or it merges automatically once verified.
